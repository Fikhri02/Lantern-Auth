# Lantern Auth — Plan Roadmap

**Spec:** `docs/superpowers/specs/2026-10-01-lantern-auth-design.md`

The spec is built in four plans. Each ends in working, tested software, and each later plan is written
**after** the previous one is finished, so it can use what the earlier build taught (especially the
spikes in §12 of the spec).
